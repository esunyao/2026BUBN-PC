# Archives and demo copies

All endpoints use the authenticated JWT subject. GET /api/v1/events/{eventId}/archive returns authorized MemoryData with transient URLs removed. MemoryService omits hidden contributions and their references.

POST /api/v1/events/import accepts {requestId,data} and returns {eventIds}. MemoryService validates and remaps graph IDs, assigns importer ownership, and makes request IDs idempotent. Confirmed photo references require importer access; inaccessible photos become explicit missing-photo placeholders. Arbitrary URLs never grant storage access or trigger external downloads.

POST /api/v1/events/from-demo accepts {requestId,demoEventId} and returns {eventId}. Source IDs are hailing and gala. Copies retain only server-controlled /demo-assets/ references from the fixture and never upload demo assets to RustFS.

The fixture src/main/resources/demo/memory-data.json is generated by executing frontend createMemoryDemo through Vite SSR, using generate-demo.mjs from this backend directory. Scene environments retain their preset names. MemoryService owns validation, sanitization, graph and photo authorization; these controllers only route metadata.
