# （二）Shared Moment World（共同时刻世界）

## 1 概述

### 1.1 一句话概念

**多人经历 = 共享世界。** 选定一次旅行、聚会、演出或毕业活动，把不同人留下的照片、视频和文字放进同一个可进入、可绕着看的三维「记忆沙盘」。每个人的记忆是一层；层层叠合，才是这件事的全貌。

### 1.2 面向谁、解决什么问题

面向一起经历过一件事、又愿意共同回顾的人。现在，同一次旅行常散在几个人的手机和社交动态里：时间线被各自的相册切开，地点也很难串起来。共同时刻世界以**一件具体事件**为单位，把「我们走过哪里、各自看见什么、这一天怎样发生」放回同一个空间。

### 1.3 整体逻辑

**选择事件 → 主动导入多人素材 → 按时间和地点归拢 → 生成记忆沙盘 → 切换视角层 → 用时间轴回放。**

沙盘是帮助回忆的三维地图：路线和场景由可确认的地点搭起，照片、视频与文字落在对应位置。它不声称仅凭相册元数据就能还原当时真实的建筑或完整三维环境。

## 2 需求分析：素材如何变成共享世界

### 2.1 数据入口与归拢方式

| 数据 | 提供什么 | 如何进入同一事件 |
| --- | --- | --- |
| 多人的照片、视频 | 拍摄时间戳、GPS 位置、画面，以及素材属于谁 | 参与者主动上传；系统按时间和地点排列，保留上传者身份 |
| 共享相册 | 已聚在一起的活动素材 | 导入后核对拍摄时间、地点和贡献者 |
| 朋友圈等动态 | 当时发布的文字、照片或视频 | 用户自行提供可分享的内容，不自动抓取社交账号 |
| 事件信息 | 名称、日期、参与者和主要地点 | 创建事件时确认；用来限定素材范围 |

同一地点、相近时间的素材聚成一个「场景点」，例如出发车站、民宿和海边；场景点按时间连成可漫游的路线。系统先给出归拢建议，再让用户确认明显的错位。照片没有 GPS 时，可依据拍摄时间放进当天时间轴，并由用户选择地点；时间也不可靠时，先放在「待放置素材」里，不硬塞进路线。

### 2.2 沙盘上的核心元素

| 元素 | 数据依据与画面含义 | 用户能做什么 |
| --- | --- | --- |
| **记忆沙盘** | 一件事件对应一个有纵深的三维小世界。主要地点以可辨认的模型、地形和标记呈现。 | 绕着沙盘看全貌，放大并进入某个场景点。 |
| **漫游路线** | 以已确认的时间和位置串起行程，如车站 → 民宿 → 海边。 | 沿路线移动，点亮沿途的照片、视频和文字。 |
| **视角层（Layer）** | 每位贡献者的素材单独成层，标明「谁记录了这一刻」。默认所有层叠合。 | 单独点亮一人，或选择几人对照，看同一地点各自拍了什么。 |
| **同刻对照** | 同一场景点里，来自不同人的素材靠近展示。 | 对比同一片海的日落、同伴背影等不同视线；点击素材看原图、视频和说明。 |
| **时间轴** | 依据素材时间与行程顺序重现事件进程。 | 拖动定位某一刻，或播放约两分钟的当天回顾，让素材沿路线依次亮起。 |

视角层切换只改变当前看到的素材，不改动共享世界的路线。场景点即使只有一个人拍到，也可以保留；没有任何人拍到的路段不补造「真实记忆」。

### 2.3 时间和位置的可信度

展示原始拍摄时间与地点前，先检查元数据是否存在、是否明显超出事件范围。跨时区旅行时统一按事件当地时间排序，并允许用户改正。多日活动可按日期浏览，每次回放选定的一天。缺少或冲突的数据标注「待确认」，由参与者补充；生成结果要能追溯到原素材，避免让推测出的路线看起来像确定事实。

## 3 使用流程：从沙盘到不同人的眼睛

1. **创建事件。** 用户填写事件名称、日期和参与者，主动导入照片、视频、共享相册或可分享的社交动态。
2. **核对路线。** 系统把素材排到时间和地点上；用户确认场景点，修正错位内容，决定哪些素材参与展示。
3. **绕沙盘漫游。** 先看到整件事的立体轮廓，再沿路线进入车站、民宿、海边等场景点。
4. **切换视角层。** 默认看所有人的素材；点亮某个人，看到「在他眼中，这一刻是什么样的」，也可回到多人叠合。
5. **回放这一天。** 拖动时间轴找某一刻，或启动两分钟回放，看各人的素材沿路线依次亮起。

这条流程要让第一次接触的人很快明白：**同一场旅行有一条共同路线，也有好几种不同的观看方式。**

## 4 首版落地与现场演示

### 4.1 最小可演示版本

首版选择**一次旅行、至少两位参与者、三个可确认地点**作为样例。完成素材导入、时间地点归拢、三维沙盘与路线、视角层切换，以及可拖动和两分钟播放的时间轴。场景模型可以是简化的立体地形与地点标记；照片、视频保持原样挂在相应位置。演示者按「看全景 → 走路线 → 换一双眼睛 → 回放一天」操作，评委也能自行尝试。

### 4.2 低门槛与缺失数据

有完整时间和 GPS 的相册，导入后即可得到路线草稿，用户只需核对。缺少 GPS 的素材仍可按时间展示，并手动选择地点；没有拍摄时间的内容先放在待放置区。若某场景只有一位贡献者，照常展示，不制造不存在的多人对照。首版不把「自动生成真实三维场景」作为演示前提。

### 4.3 分享边界

每位贡献者决定自己哪些素材进入事件，导入前说明参与者和展示范围；私人或不宜公开的内容可以排除。地点可能暴露住址或行动轨迹，分享给活动参与者之外的人之前，需要检查并可隐藏精确位置。朋友圈内容只使用用户主动提供、允许分享的部分。

## 5 体验目标与验收

打动人的一刻是：**「同一场旅行，我们记住的原来是两个不同的世界。」** 切到另一个人的视角，地点和时间没有变，眼前的画面却变了；再叠回所有人的层，才看见共同经历有多丰富。

首版验收看四件事：每份素材能找到贡献者和原始来源；路线顺序与确认过的时间、地点一致；切换视角层后只显示选中人的素材；时间轴可定位和完整播放当天回顾。数据不足时清楚标注并允许修正，不把猜测包装成真实场景。
