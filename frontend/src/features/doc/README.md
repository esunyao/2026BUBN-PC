# 功能模块

| 模块     | 入口                              | 输入与结果                                                         |
| -------- | --------------------------------- | ------------------------------------------------------------------ |
| world    | WorldMap.vue                      | 岛、照片、角色位置和主题；发出 navigate/manualMove，维护自身相机   |
| memories | MemoryPanel.vue                   | 当前岛、过滤后的照片和人物；查看回忆和可关闭的大图                 |
| import   | ImportPanel.vue / importPhotos.ts | 本批拍摄者、图片与现有岛；交付新增岛、成功照片、失败列表与安放请求 |
| replay   | useReplay.ts / ReplayBar.vue      | 可见照片、导航函数；输出120秒进度、播放状态与当前照片              |

## 导入规则

每批一位拍摄者。图片先检查能否显示，再读取 EXIF；缺少元数据不妨碍图片使用。GPS 距每组第一张照片固定锚点300米以内合并，多个地点命中时选最近；不做链式传递归并。无 GPS 的照片 islandId=null，等待手动安放。缺少拍摄时间保持未知，不用文件修改时间冒充。

新岛使用 shared/lib/layout.ts 的稳定槽位，外观循环使用十种岛型。回放按拍摄时间排序，未知时间按导入顺序追加，保留多次到访同地点；待安放照片在确定地点后才加入回放。手动操作由 app 中断回放，回放通过注入的 navigateTo 复用导航。

## 修改后检查

导入测试检查299/301米、固定锚点、最近地点、坏文件继续；回放测试检查120秒时钟、seek和取消旧回调。地图视觉与真实 EXIF 文件导入需要浏览器验证。
