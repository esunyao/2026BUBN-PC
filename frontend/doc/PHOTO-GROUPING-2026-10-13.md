# 照片归类 MVP · 2026-10-13

入口：主导航「照片归类」→ 选择一批照片和一位记录者 → 审阅候选事件 → 改名、改类型、补时间、移动照片或取消选择 → 确认保存。保存后进入事件，Scene/Timeline/Constellation 使用同一 MemoryData，刷新读取 IndexedDB 照片。当前不改后端或 HTTP 契约；[日期 OpenAPI](2026-10-13.openapi.json) 仍只摘要现有服务器接口。

## 归类依据

- EXIF 真实时间和 GPS 优先；没有时间时不用文件修改时间代替，不凭画面推断日期。EXIF 未提供时区时按设备本地时间读取，允许用户修正并标记 user 来源。
- 默认同日、相邻间隔 3 小时、距首张有效 GPS 30 km、总跨度不超过 12 小时。可调整时间/位置尺度；固定位置锚点避免链式扩散。跨日旅行可手动合并，自动建议不推断整段行程。
- 图片嵌入余弦相似度作为辅助：有可靠时间/近距离 GPS 时允许不同画面同组；缺 GPS 时画面差异明显则分开。阈值 0.8 是保守启发式，尚未经过用户照片集校准，不是概率。
- 没有可信时间的照片单独待确认。完全相同的文件通过 SHA256 在本批跳过副本，不删除原图；不同压缩/裁剪版本不作精确重复承诺。
- 审阅后，每个事件再按 GPS 固定 300 米分章节、30 分钟分时刻。没有 GPS 留在「位置待确认」；没有拍摄时间的照片保持 unknown，手动事件日期仅给导航提供上下文，不写成 EXIF。

## 模型与性能

采用 [官方 MobileNetV3 Small](https://developers.google.com/edge/mediapipe/solutions/vision/image_embedder)，相比引入 CLIP 和文本编码器，更适合当前只需图片相似度的 MVP。真实本地模型推理，不沿用 Demo 的 MockVisionProvider；[模型与运行时来源](../public/models/README.md)。不识别人脸、不生成心情，也不自动给图片贴语义标签。

JS 动态导入，模型和 WASM 仅分析时加载。照片缩放至 224×224，逐张 CPU 推理，每张之间让出事件循环；当前仍在主线程执行单次推理，每批限制 60 张、120 MB、单张 12 MB。低端设备可取消或关闭画面辅助；加载/单张分析失败明确降级到时间和位置，不能假装已分析。向量仅用于本批候选，不保存到 localStorage。

## 持久化与范围

先构造并验证事件数据，再通过同一 IndexedDB 写事务保存所选照片，成功后发布 MemoryData。存储失败不发布候选事件。记录者在本地是 Demo 身份选择，不代替服务器鉴权。新事件不会擅自修改或合并已有事件；没有地点命名服务、自动理解长期活动阶段或后端同步。

## 篇章流程增量

当前流程为创建篇章后一次导入，默认自动归类、生成标题简介、保存并打开篇章。MemoryEvent 是篇章容器，Scene 是其中一个事件，Moment 是时刻。单张和线索不足的照片进入 pendingPhotos，保留原图及 HEIC JPEG 预览；追加导入时本人待整理照片重新参与归类。可手动收录到已有事件或独立事件。关闭自动保存可先审阅。

没有可信时间时，画面相似或近位置可支持分组，贡献的时间精度仍保持 unknown，导航日期不当作真实拍摄时间。每批上限 500 张/2 GB/单张 30 MB。DeepSeek 仅收到代表缩略图与日期、篇章标题，失败回退本地；内容始终与用户原文分开。
